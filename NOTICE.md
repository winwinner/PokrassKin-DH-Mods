# Authorship / Авторство

## EN

Parts of this project are based on older Dread Hunger community code that was
passed around between server operators without author names or a license. **The
original authorship has been lost.** If you are the author of any of it, please
open an issue: we will credit you or remove the code, as you prefer.

| Item | Origin | License |
|---|---|---|
| `server/scripts/force_match_end.js` | ours | MIT |
| `lobby/Patches/[Dock Patch] Lobby Respawn.js` | ours | MIT |
| `lobby/Patches/[Dock Patch] Lobby Corpse Cleanup.js` | ours | MIT |
| `lobby/Patches/[Dock Patch] Lobby Duel.js` | ours | MIT |
| `server/scripts/thrall_weight.js` | based on a community weighted-thrall script (author unknown); the rewrite and the role-decline phase are ours | ours: MIT; original part: unknown |
| `server/scripts/questsinstant.js` | based on a community quest-rewards script (author unknown); the direct quest start is ours | ours: MIT; original part: unknown |
| `server/scripts/train_mode.js` | based on a community script with Japanese comments (author unknown); starting items, knockdown/revive and fist healing are ours | ours: MIT; original part: unknown |
| `runner.exe` (Releases) | third-party Frida-based injector, author unknown, distributed as-is | unknown |

The `[Dock Patch]` prefix on the lobby mods only groups them with other lobby
patches of that name (码头 means "dock"). It does not mean they were written by
the authors of the other `[Dock Patch]` scripts.

Frida is developed by the Frida project (https://frida.re) under the wxWindows
Library Licence.
