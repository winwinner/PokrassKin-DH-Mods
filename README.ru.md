# PokrassKin DH Mods

[English version](README.md)

Frida-моды для **Dread Hunger**, которые работают на серверах сообщества PokrassKin.

Здесь два независимых набора для разных машин:

| Набор | Где работает | Загрузчик | Моды |
|---|---|---|---|
| [`server/`](server/README.ru.md) | выделенный игровой сервер | `runner.exe` (см. [Releases](../../releases)) | веса предателей + отказ от роли, принудительное завершение матча, квесты сразу, тренировочный режим |
| [`lobby/`](lobby/README.ru.md) | ПК игрока, который **создаёт лобби** | Frida Gadget, папка `Patches` | респавн в лобби, уборка трупов в лобби, дуэли в лобби |

## Сборка игры

Все моды правят игру по жёстко заданным адресам, поэтому работают **только**
с этими исполняемыми файлами. На другой сборке они, скорее всего, уронят
процесс. Сверьте хэш перед установкой.

| Файл | Размер | Хэш |
|---|---|---|
| `DreadHungerServer-Win64-Shipping.exe` | 76 583 424 | MD5 `a784ea380ef981c93619052bc12bae18` |
| `DreadHunger-Win64-Shipping.exe` (клиент) | 82 631 680 | SHA-256 `897a596e5c7d309b8aad6c5796d3b3651a5147bcc0e912522c30a3ee6ab02bf6` |

Для справки: у нас установлен TotemMod v1.1.4.

```bash
md5sum DreadHungerServer-Win64-Shipping.exe          # Linux
```
```powershell
Get-FileHash DreadHunger-Win64-Shipping.exe          # Windows, SHA-256
```

## Настройки

В начале каждого мода есть блок настроек с комментариями на английском и
русском. Флаги: `1` - включено, `0` - выключено. Поправили, сохранили,
перезапустили сервер (или пересоздали лобби). Сообщения игрокам в игре - на
русском.

## Логи

Моды дописывают текстовые файлы в `Binaries/Win64` рядом с exe игры:
`output.log` (большинство модов) и `train_mode.log` (тренировочный режим).

## Лицензия и авторство

Наш код - под [лицензией MIT](LICENSE). Часть модов построена поверх старого
кода сообщества, авторство которого утеряно; то же касается `runner.exe`.
Что именно наше, а что нет - в [NOTICE.md](NOTICE.md).

Dread Hunger - товарный знак его владельцев. Проект с ними не связан. Файлы
игры здесь не распространяются.
