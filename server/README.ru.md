# Серверные моды

[English version](README.md) · [На главную](../README.ru.md)

Frida-скрипты для **выделенного сервера** Dread Hunger
(`DreadHungerServer-Win64-Shipping.exe`, MD5 `a784ea380ef981c93619052bc12bae18`).

| Скрипт | Что делает |
|---|---|
| [`thrall_weight.js`](scripts/thrall_weight.js) | Две функции, у каждой свой выключатель: **веса** (предатели выбираются по весам, привязанным к Steam ID) и **отказ от роли** (роли раздаются за покерным столом, предатель может отказаться за 10 с, роль уходит другому). |
| [`force_match_end.js`](scripts/force_match_end.js) | Завершает идущий раунд победой экипажа или предателей, когда вы создаёте файл-флаг. |
| [`questsinstant.js`](scripts/questsinstant.js) | Через 40 с после начала раунда каждый получает квест без свитка; за квест - случайные предметы. **Экспериментально.** |
| [`train_mode.js`](scripts/train_mode.js) | Тренировка: стартовое оружие, без отката заклинаний, мгновенный крафт, бесконечные патроны, нокдаун вместо смерти, замах кулаком лечит. |

## Что нужно

- Сборка сервера, указанная выше. На других не заработает.
- `runner.exe` из [Releases](../../../releases) (69 МБ, SHA-256
  `0fcb79b6eb7c2c38475e545b6ad9dd21885e2c445e0d19c17e1d5fadc89feaa4`). Это
  загрузчик на Frida: запускает сервер и внедряет перечисленные скрипты. Автор
  неизвестен, см. [NOTICE.md](../NOTICE.md).
- У нас сервер работает на **Linux под Wine** (Ubuntu 24.04, Wine 9.0).
  `runner.exe` - обычная Win64-программа, так что на Windows тоже должно
  работать, но мы это не проверяли.

## Установка

1. Положите `runner.exe` в корень сервера, рядом с папкой `WindowsServer`.
2. Рядом с `runner.exe` создайте папку `scripts` и скопируйте туда моды.
   `runner.exe` ищет скрипты в `./scripts`.

```
<корень сервера>/
├── runner.exe
├── scripts/
│   ├── thrall_weight.js
│   ├── force_match_end.js
│   ├── questsinstant.js
│   └── train_mode.js
└── WindowsServer/DreadHunger/Binaries/Win64/DreadHungerServer-Win64-Shipping.exe
```

3. Поправьте блок настроек в начале каждого нужного скрипта (см. ниже).

## Запуск

Сервер запускается через `runner.exe` из корня сервера. Аргументы: exe сервера,
строка карты, затем имена скриптов (только имена, без папки):

```bash
cd /путь/к/корню-сервера
wine runner.exe WindowsServer/DreadHunger/Binaries/Win64/DreadHungerServer-Win64-Shipping.exe \
  "Expanse_Persistent?maxplayers=8?thralls=2?port=7777" \
  thrall_weight.js force_match_end.js
```

На Windows - та же строка без `wine`. В выводе будет `injected: <имя>.js` для
каждого загруженного скрипта. Набор скриптов любой: они друг от друга не зависят.

Один процесс сервера обслуживает **один матч** и завершается после него.
Скрипты на это рассчитаны и не хранят состояние между матчами, поэтому на
каждый матч - новый процесс (так игровой сервер и работает).

## Настройки

### thrall_weight.js

| Настройка | По умолчанию | Значение |
|---|---|---|
| `WEIGHTS_ENABLED` | `1` | Выбор предателей по весам: вкл/выкл. |
| `WEIGHT_TABLE` | `[]` | `[["<steamid64>", бонус], ...]`. Вес игрока = `BASE_WEIGHT + бонус`, не меньше `MIN_WEIGHT`. |
| `BASE_WEIGHT` | `100` | Вес любого игрока не из таблицы. |
| `MIN_WEIGHT` | `1` | Минимальный вес. |
| `DECLINE_ENABLED` | `1` | Отказ от роли: вкл/выкл. |
| `DECLINE_ROLL_AT_MS` | `30000` | Когда раздать роли после посадки за стол (сама игра делает это примерно на 45 с). |
| `DECLINE_WINDOW_MS` | `10000` | Сколько времени у предателя на отказ. |
| `DECLINE_DESTROY_SPELLBOOK` | `1` | Удалять книгу заклинаний у отказавшегося. |
| `MSG_*` | текст на русском | Сообщения игрокам в чате кольца предателей. |

Пример: бонус `+100` даёт игроку вдвое больше шансов, чем остальным, `-50` -
вдвое меньше. Таблица читается один раз, при запуске сервера.

**Отказ от роли глазами игрока.** Примерно через 30 с после посадки за покерный
стол предатель получает сообщение в чате кольца. Чтобы отказаться, за 10 с
нажмите **T** и отправьте любую команду кольца; молчание - согласие. Роль
уходит случайному игроку не из предателей, у него выбора нет. Если передать
некому, отказавшийся остаётся предателем.

### force_match_end.js

| Настройка | По умолчанию | Значение |
|---|---|---|
| `FLAG_DIR` | `C:/DreadHunger` | Папка, где скрипт ищет файлы-флаги. Абсолютный путь Windows с прямыми слешами. Под Wine пути Linux находятся на диске `Z:`, например `Z:/home/dh/dreadhunger`. |

Во время раунда создайте пустой файл в `FLAG_DIR`:

```bash
touch /home/dh/dreadhunger/force_win_civilians.flag   # победа экипажа
touch /home/dh/dreadhunger/force_win_thralls.flag     # победа предателей
```

Через пару секунд флаг исчезнет, а в `force_win_result.flag` появится итог:
`ended ...` (готово), `rejected <состояние>` (раунд не идёт, например в лобби),
`no-effect ...` или `error ...`.

### questsinstant.js

`QUEST_START_DELAY_MS` (40 с после начала раунда), `TaskRewardsnumber` /
`ThrallTaskRewardsnumber` (сколько предметов за квест экипажу / предателям) и
таблицы наград `InventoryTable` / `ThrallInventoryTable` (чем больше `weight`,
тем чаще). В полном живом раунде ещё не подтверждено.

### train_mode.js

`STARTING_ITEMS` (с чем появляется каждый игрок), `ReviveDelayMs` (сколько
лежать в нокдауне). Лог - `train_mode.log`.

## Если не работает

- **Сервер падает сразу после старта** - не та сборка сервера. Сверьте MD5.
- **Скрипт ничего не делает** - проверьте, что в выводе runner есть
  `injected: <имя>.js`, и загляните в `output.log` в `Binaries/Win64`.
- **force_match_end не отвечает** - `FLAG_DIR` указывает не туда, где вы
  создаёте флаг. Под Wine не забудьте префикс `Z:`.
